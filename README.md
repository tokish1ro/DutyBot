# 🤖 DutyBot - Telegram Bot для управления дежурствами

Автоматизированный бот для распределения дежурств в учебных группах. Работает 24/7 в облаке.

##  Возможности

- ➕ Добавление студентов в список
- 🔄 Автоматическая ротация дежурных  
- 💾 Облачная база данных (Supabase)
- 🎯 Удобные кнопки управления
- 📊 Просмотр списка группы
- 🌐 Работа 24/7 на Render

## 📚 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота |
| `/add <имя>` | Добавить студента |
| `/list` | Показать список |
| `/today` | Дежурные сегодня |
| `/remove <номер>` | Удалить студента |

## 🛠 Технологии

- **Backend:** C# (.NET 10)
- **Telegram API:** Telegram.Bot
- **База данных:** Supabase (PostgreSQL)
- **Хостинг:** Render
